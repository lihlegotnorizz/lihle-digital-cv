# Lihle Naholo — Digital CV

A responsive, single-page digital CV for Lihle Naholo, built with semantic HTML, CSS, and a small amount of JavaScript. The design is based on the CV details provided by Lihle and highlights their studies, leadership, skills, and GitHub project.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. For example:

```sh
npx serve .
```

## Publish with GitHub Pages

1. Create a public repository on GitHub and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The site respects reduced-motion preferences and does not require a build step.
